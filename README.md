# ars-nova-bridge

**Ars Nova Singers - custom WordPress plugin.** Canonical source (private use; not distributed).

- Current version: 1.1.0 (matches DEV; recovered from Kinsta backup 2026-07-23)
- Environment: DEV only; not on LIVE.
- Exposes theme_mods (Kadence/Customizer settings), read-only options, and read-only theme source files over the REST API so the Ars Nova WordPress connector can read/write theme settings by command. Admin-only. v1.1.0.

Releases: each tag v<version> attaches the installable zip (top folder ars-nova-bridge/).
